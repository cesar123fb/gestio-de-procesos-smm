# Gestión de proyectos — Manufactura y soldadura

Sistema para talleres de metalmecánica y soldadura: proyectos con etapas, tareas por responsable con urgencias,
cotizaciones y órdenes de compra, almacén, calidad, certificaciones de soldadores y máquinas. Pensado para el celular
y para personal con poca experiencia en sistemas.

Hay dos versiones con la **misma interfaz**:

| | Datos en | Velocidad | Guía |
|---|---|---|---|
| **Firebase (recomendada)** | Firebase, con respaldo automático en Google Sheets | Al instante, en tiempo real, funciona sin señal | [firebase/README.md](firebase/README.md) |
| Apps Script | Google Sheets directamente | 1–3 s por cambio | [gestion-proyectos/README.md](gestion-proyectos/README.md) |
